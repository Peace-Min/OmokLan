# 📖 LAN 오목 (OmokLan) 위키

폐쇄망(인터넷 차단 환경)에서 같은 로컬 네트워크(LAN) 상의 동료들과 별도의 서버 없이 P2P로 즐길 수 있는 Windows 네이티브 오목 게임입니다.

---

## 📌 주요 특징
- **100% 무설치 단일 실행 파일 (`OmokLan.exe`)**: .NET 런타임이 설치되어 있지 않은 Windows PC에서도 바로 실행됩니다.
- **외부 인터넷 연결 불필요**: 클라우드 서버나 외부 라이브러리 의존성 없이 로컬 네트워크 내에서만 작동합니다.
- **자동 사용자 탐색 (UDP Broadcast)**: 같은 망에 앱을 켜둔 사용자가 로비 목록에 실시간으로 자동 표시됩니다.
- **방해금지 (DND) 모드**: 집중이 필요한 업무 중에는 대결 신청을 자동으로 거절합니다.
- **흑/백 결정 코인 토스**: 대결 시작 시 3D 회전 애니메이션의 황금 코인 토스로 선공(흑)을 공정하게 자동 결정합니다.
- **30초 턴 제한**: 긴장감 있는 대국을 위해 30초 턴 제한시간이 적용되며, 시간 초과 시 시간패 처리됩니다.
- **실시간 인게임 채팅**: 대국 중 상대방과 자유롭게 대화를 나눌 수 있습니다.
- **닉네임 및 아바타 상시 편집**: 언제든 상단 프로필 버튼을 눌러 내 아바타와 닉네임을 변경할 수 있습니다.
