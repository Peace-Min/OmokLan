# 🎮 사용자 가이드 (User Guide)

## 1. 최초 실행 및 프로필 설정
1. `OmokLan.exe`를 실행합니다.
2. 최초 실행 시 **프로필 설정 팝업**이 나타납니다.
   - **닉네임 입력**: 2자 이상 12자 이하로 입력합니다.
   - **아바타 선택**: 8종류의 프리셋 아바타(고양이, 강아지, 여우, 판다, 사자, 우주비행사, 왕관, 번개) 중 마음에 드는 아바타를 클릭합니다.
   - **저장 및 시작**을 누르면 로비로 이동합니다.
3. **프로필 언제든 수정하기**:
   - 상단 타이틀바 우측의 **[내 프로필 카드]**를 클릭하면 언제든지 닉네임과 아바타를 변경할 수 있습니다.
   - 변경 즉시 네트워크 비컨과 현재 진행 중인 게임 세션에 실시간 반영됩니다.

---

## 2. 로비 및 대결 신청
- **접속자 목록**: 같은 LAN 네트워크 상에서 앱을 켜둔 사용자가 카드 형태로 자동 표시됩니다.
- **방해금지 (DND) 모드**:
  - 상단 토글 스위치를 켜면 **방해금지** 모드로 전환됩니다.
  - 방해금지 모드일 때는 다른 사용자가 나에게 대결을 신청할 수 없으며, 상대방 목록에서 버튼이 비활성화되거나 자동 거절됩니다.
- **대결 신청하기**:
  - 상태가 **[대기중]**인 사용자의 카드에서 `⚔️ 대결 신청` 버튼을 누릅니다.
  - 상대방의 수락 대기 창이 뜨며, 원할 경우 `신청 취소`가 가능합니다.
- **대결 신청 받기**:
  - 다른 사용자가 나에게 대결을 신청하면 수락/거절 팝업이 뜹니다.
  - 20초 카운트다운 동안 `수락`을 누르면 즉시 게임 화면으로 전환됩니다.

---

## 3. 대국 진행 및 규칙
1. **코인 토스 (선공 결정)**:
   - 게임 화면에 진입하면 중앙에 3D 회전하는 황금 코인 토스 연출이 나타납니다.
   - 양면 중 윗면으로 멈춘 플레이어가 **흑(선공)**이 되고, 반대편 플레이어가 **백(후공)**이 됩니다.
2. **착수 (돌 놓기)**:
   - 본인 차례일 때 15x15 오목판에 마우스를 올리면 **반투명 미리보기 돌**이 표시됩니다.
   - 원하는 교차점을 클릭하면 착수가 완료되며 상대방 화면에도 즉시 반영됩니다.
   - 마지막 착수 위치에는 금색 링이 표시됩니다.
3. **30초 턴 제한시간**:
   - 매 턴마다 30초 카운트다운 타이머가 작동합니다.
   - 10초 이하로 떨어지면 붉은색 경고로 전환되며, 0초가 되면 **시간패**로 판정됩니다.
4. **오목 룰 (자유룰)**:
   - 가로, 세로, 대각선 중 연속해서 5개 이상 돌을 놓으면 즉시 승리합니다 (6목 이상 장목도 승리로 인정).
5. **실시간 채팅**:
   - 우측 채팅창을 통해 상대방과 자유롭게 대화할 수 있습니다. (메시지 입력 후 Enter 키 또는 전송 버튼 클릭)
6. **기권 및 재대결**:
   - 불리한 상황에서는 `🏳️ 기권` 버튼을 눌러 패배를 인정할 수 있습니다.
   - 대국이 끝나면 결과 창에서 `🔄 재대결 신청`을 눌러 다시 승부를 겨룰 수 있습니다 (재대결 시에도 코인 토스로 선공 결정).
