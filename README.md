# 🎯 LAN 오목 (OmokLan)

> **폐쇄망(인터넷 차단 환경)에서도 동료들과 함께 즐길 수 있는 Windows P2P 오목 데스크톱 앱**  
> 중앙 서버 없이 **UDP 브로드캐스트**로 주변 사용자를 자동 탐색하고, **TCP 1:1 P2P 세션**으로 실시간 대국을 진행합니다.

---

## ✨ 주요 기능

1. **100% 무설치 단일 실행 파일 (`OmokLan.exe`)**
   - 대상 PC에 .NET 런타임이나 SDK가 설치되어 있지 않아도 단독 실행 가능 (Self-Contained)
   - 외부 인터넷/클라우드 의존성 0%
2. **로컬 네트워크 자동 탐색 (UDP 47800 브로드캐스트)**
   - 앱을 실행하면 같은 서브넷(LAN) 상의 동료들이 로비에 실시간으로 표시됩니다.
   - 6초 동안 신호가 없으면 목록에서 자동 정리됩니다.
3. **방해금지 (DND) 모드**
   - 상단 토글을 켜면 방해금지 모드로 전환되며, 대결 신청을 자동으로 거절합니다.
4. **황금 코인 토스 (3D 플립 연출)**
   - 대결 시작 시 3D 회전 애니메이션의 코인 토스를 통해 선공(흑)과 후공(백)을 공정하게 자동 배정합니다.
5. **30초 턴 제한시간**
   - 긴장감 있는 대국을 위해 30초 카운트다운 타이머가 작동하며, 시간 초과 시 시간패로 처리됩니다.
6. **실시간 인게임 채팅**
   - 대국 도중 우측 채팅창을 통해 상대방과 자유롭게 대화할 수 있습니다.
7. **닉네임 및 아바타(8종) 상시 편집**
   - 최초 실행 시 프로필 설정 및 타이틀바 우측 내 프로필 클릭 시 언제든 닉네임과 아바타를 변경할 수 있습니다.
8. **15×15 자유룰 판정 엔진**
   - 가로, 세로, 대각선 5목 이상 연속 착수 시 즉시 승리 (6목 이상 장목도 승리로 인정)
   - 마우스 호버 반투명 착수 가이드, 마지막 착수 골드 링, 승리 라인 네온 글로우 하이라이트

## 🛠️ 기술 스택

- **언어/런타임**: C# 13 / .NET 9.0 (WPF)
- **네트워크**: `System.Net.Sockets` (UDP Broadcast + TCP Framing)
- **직렬화**: `System.Text.Json`
- **테스트**: xUnit 2.9.2 (규칙, 프레이밍, 네트워크 핸드셰이크, E2E 통합 테스트 15건)
- **의존성**: 런타임 외부 NuGet 의존성 없음 (순수 .NET 내장 라이브러리)

## 🚀 빠른 시작

### 1. 배포 패키지 실행 (폐쇄망 권장)
- `publish/win-x64/OmokLan.exe`를 실행합니다.
- 설치 과정 없이 즉시 실행되며, 로비에서 같은 망의 동료에게 `대결 신청`을 보냅니다.
- *혼자 테스트하실 경우 로비 상단의 `[🤖 AI 연습 상대 소환]`을 누르면 실제 UDP/TCP로 참여하는 연습 봇과 즉시 플레이하실 수 있습니다.*

### 2. 소스코드 빌드
```bash
# 저장소 복제
git clone https://github.com/Peace-Min/OmokLan.git
cd OmokLan

# 테스트 실행
dotnet test

# 단일 실행 파일 배포 빌드
dotnet publish src/OmokLan/OmokLan.csproj -c Release -r win-x64 -o publish/win-x64 --self-contained true -p:PublishSingleFile=true
```

## 📡 네트워크 프로토콜 규격

- **탐색 (Discovery)**: `UDP 47800` (2초 주기 비컨 JSON 브로드캐스트)
- **대결 (Duel)**: `TCP 47801~47810` (4바이트 Big-Endian 길이 접두 프레이밍)

상세한 프로토콜 및 아키텍처는 [docs/wiki/Architecture_and_Protocol.md](docs/wiki/Architecture_and_Protocol.md)를 참고하세요.
