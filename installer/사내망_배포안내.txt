================================================================
           LAN 오목 (OmokLan) - 사내망/폐쇄망 배포 안내서
================================================================

1. 프로그램 개요
----------------------------------------------------------------
- 본 프로그램은 외부 인터넷 접속이나 중앙 DB/서버가 전혀 필요 없는
  순수 사내 폐쇄망(LAN) P2P 1:1 오목 대전 데스크톱 애플리케이션입니다.
- .NET 런타임이 사전 포함(Self-Contained)되어 있어 별도의 닷넷 설치 없이
  Windows 10 / 11 환경에서 즉시 실행됩니다.

2. 권장 설치 방법 (일반 사내 사용자)
----------------------------------------------------------------
1) 'OmokLan_Setup_v1.1.1.exe' 파일을 더블 클릭하여 실행합니다.
2) 설치 마법사의 안내에 따라 설치를 진행합니다.
   * 관리자 권한이 필요하지 않으며, 현재 사용자 전용 공간
     (%LOCALAPPDATA%\Programs\LAN 오목)에 설치할 수 있습니다.
   * 시작 메뉴 바로가기가 생성되며, 바탕화면 바로가기는 선택할 수 있습니다.
3) 바탕화면의 'LAN 오목' 아이콘을 클릭하여 게임을 즐기시면 됩니다.

3. 포터블(무설치) 실행 방법
----------------------------------------------------------------
- 별도 설치 없이 바로 실행하고자 할 경우, 'OmokLan.exe'를 직접 실행하시면 됩니다.
  (USB, 사내 공용 공유 폴더 등에서도 바로 실행 가능)

4. 사내 방화벽 및 네트워크 필수 확인 사항
----------------------------------------------------------------
- UDP 47800 포트 (사내 동일 서브넷 사용자 자동 탐색용 브로드캐스트)
- TCP 47801~47810 포트 중 사용 가능한 포트 (1:1 실시간 대국 및 채팅)
* Windows 방화벽 경고 팝업 시 [액세스 허용 (개인/사내 네트워크)]을 반드시 허용해 주세요.

5. 프로그램 제거 방법
----------------------------------------------------------------
- Windows 설정의 설치된 앱 또는 시작 메뉴의 'LAN 오목 제거'를 통해 제거합니다.
